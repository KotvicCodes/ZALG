# Factor Polynomials
> x^2 - 3x + 2  →  (x - 1)(x - 2)

To access the true power of this program, run the python script and check your command line.

Available commands:
* `exit` — quit
* `file` — load from file

The polynomials inputted should follow standard polynomial form:
* `ax^n + ... + B`, any order
* one variable only
* number multiplication ok (e.g. `2*13x`)
* no variable multiplication
* spaces ignored
* one polynomial per line
* no brackets
* integer coefficients only

# Multiply Factored Polynomial
> (x - 1)(x - 2)  →  x^2 - 3x + 2

So long you add brackets to the expression, multiplying factored polynomial mode will kick in. This mode has also some limitations:
* no trailing expressions (e.g. `(x + 1)(x - 2)2x`)
